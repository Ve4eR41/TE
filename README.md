# Troll vs Elves

Браузерная игра: один тролль против N эльфов, матч на 30 минут.
Выполнены specs 001–003 и 005–012: монорепозиторий, конфиги, базовые типы,
сетевой протокол, WS-сервер и первая игровая прогулка по лесу.
Работают движение, коллизии, несколько игроков, таймер и фазы. Есть ресурсы, стены и улучшение; бой впереди.

## Подготовка

Нужны Node.js из `.node-version` (24 LTS) и pnpm из `packageManager` в package.json.
Если pnpm ещё нет, установите закреплённую версию: `npm install -g pnpm@11.28.6`.
Из корня репозитория:

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm lint
pnpm build
```

`pnpm format` исправляет форматирование. Typecheck сначала собирает shared;
build выполняет сборку пакетов в порядке зависимостей. Есть тесты конфигов и протокола,
интеграционные тесты WS-сервера и проверки жизненного цикла клиентского подключения.
Пакеты: `@troll-vs-elves/shared`, `@troll-vs-elves/server`, `@troll-vs-elves/client`.
Для проверки отдельного пакета: `pnpm --filter @troll-vs-elves/shared test`.

## Конфиги и shared API

Схемы и типы импортируются из `@troll-vs-elves/shared`. Серверный загрузчик
`loadConfig(rootDir)` и `ConfigError` доступны отдельно через
`@troll-vs-elves/shared/config/node`. rootDir указывает на каталог `config/`,
а не на корень репозитория. Браузерный entry point не использует Node I/O.
Загрузчик не кеширует данные: будущий сервер должен вызвать его один раз до матча.
Значения характеристик сущностей ещё не утверждены.

## Серверный каркас (spec 006)

```sh
pnpm dev:server
```

Готовность: `http://127.0.0.1:3001/health`, WS: `/ws`. Остановка — Ctrl+C.
Можно задать HOST, PORT и GAME_CONFIG_DIR. По умолчанию конфиги находятся
относительно server/dist, поэтому команда не зависит от текущего каталога.
Сервер обслуживает одну временную комнату, движение и снапшоты с частотой из конфига.

## Игровая проба (specs 007–010)

После установки зависимостей запустите из корня репозитория:

```sh
pnpm dev
```

Команда собирает shared/server и запускает игровой сервер вместе с Vite.
Ctrl+C останавливает оба процесса. Если один завершится, второй тоже будет
остановлен, а ошибка останется видна в терминале. Оба порта должны быть свободны.
Для раздельной отладки доступны `pnpm dev:server` и `pnpm dev:client` в двух терминалах.

Откройте `http://localhost:5173/`: подключение происходит автоматически. Vite
проксирует /ws и /health к server:3001; в браузере используется origin страницы,
в том числе wss при HTTPS. Для остановки общей команды — Ctrl+C.
Текущая proxy-конфигурация предназначена для локальной разработки.

## Управление

- Клик или тап по земле — идти к точке. WASD / стрелки — движение.
- Обходите деревья и пруд: автоматического поиска пути пока нет.
- Первый участник — тролль, остальные — эльфы; до 8 участников.
  Откройте вторую вкладку, чтобы увидеть другого героя и его стены в той же комнате.
- «Выйти из леса» завершает подключение. Повторный вход даёт нового персонажа.
- Прогулка длится 30 минут; на нуле движение останавливается.
  Для новой пробы все участники должны выйти, затем войти снова.

Это прототип движения и строительства: боя, найма юнитов и победы пока нет.
Графика PixiJS процедурная, без внешних ассетов. Геометрия и параметры персонажей
загружаются сервером из JSON с Zod-валидацией. Это временные настройки пробы.
Production-сборка клиента находится в packages/client/dist; deploy — отдельный этап.

## Что проверить в версии 0.3

1. В списке «Твой герой» выберите «Эльф · строитель». Ресурсы начнут со 120/120;
   золото и дерево растут со временем (временный доход 2/3 в секунду).
2. Нажмите «Стена», затем на свободную землю рядом с героем. Цена: 30 золота,
   40 дерева. Стена появляется в обеих вкладках и мешает движению.
3. Нажмите «Отменить» / Escape, затем на стену: видны её HP и уровень.
   «Улучшить» стоит 40 золота/30 дерева и повышает HP с 200 до 400 один раз.
4. Попытки построить на дереве, пруде, спавне, игроке или другой стене отклоняются.
   Дальние точки и нехватка ресурсов также дают пояснение без выхода из игры.
5. Выход удаляет свои стены и ресурсы. Повторный вход начинает заново.

Максимум шесть стен эльфа. Для одиночной пробы боя пока нет: тролль ходит по арене.

## Восстановление соединения (012a)

Если сервер временно недоступен, страница повторяет подключение через 2, 4, 8,
затем каждые 10 секунд. «Отменить подключение» прекращает повторы. После запуска
сервера страница входит сама; перезагрузка не нужна. **Это новый вход**: персонаж,
ресурсы и стены прежней сессии не сохраняются. Смена роли отменяет старую попытку.
Занятый тролль и заполненная комната требуют выбора роли / ручного повторного входа.

Проверка готовности всей цепочки: `curl --fail http://localhost:5173/health`.
Ответ — JSON со `status: "ok"`. Если Vite открыт, но этот запрос не проходит,
проверьте терминал общей команды. Preview должен восстанавливаться командой
`pnpm dev`, чтобы поднимались оба процесса.

## Игра на весь экран (012b)

Интерфейс сразу заполняет окно: сверху роль, ресурсы и таймер, снизу строительство.
Карта занимает оставшееся место, камера следует за вашим героем и ограничена
краями леса. Кнопка ⛶ включает полный экран браузера; повторное нажатие или Escape
выключает его. На устройствах без Fullscreen API игра заполняет доступное окно.
На телефоне можно ходить и строить тапом; WASD и стрелки работают с клавиатуры.
