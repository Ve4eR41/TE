# 012b — Игровой экран на всё окно

## Цель

По запросу пользователя заменить посадочную страницу игровым интерфейсом на весь
viewport, сохранив процедурный лес. Читать conventions и architecture.

## Контракт

- Карта занимает всё свободное пространство между компактной верхней панелью
  и нижними действиями. Прокрутка страницы для игры не нужна.
- Роль, вход/выход, состояние соединения, таймер, ресурсы, стены и улучшение
  доступны на desktop и mobile; панели не перекрывают клики по карте.
- Камера заполняет область карты без растяжения мира и следует за своим героем.
  Ограничить её краями карты. Координаты интентов вычислять из текущей камеры.
  Это визуальное изменение; серверная геометрия/видимость/баланс прежние.
- Кнопка «Полный экран» включает/выключает браузерный Fullscreen API по нажатию;
  Escape и отказ API корректно отражаются в интерфейсе. Без поддержки API кнопка
  скрыта, игра всё равно заполняет окно. Не перехватывать стрелки при выборе роли.
- При узком/низком viewport второстепенные подписи компактнее; действия доступны.
- Не добавлять зависимости, игровые механики и изменения конфигов/протокола.

## DoD

Тесты преобразования камеры и границ; pnpm typecheck/test/lint/build.
Browser desktop, portrait/landscape mobile: нет overflow, панели видны, движение,
постройка/выбор/upgrade, камера на краях, resize, подключение/отмена и fullscreen.
