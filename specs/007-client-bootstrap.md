packages/client/**, scripts package.json, lockfile, README, docs/architecture.md.
Разрешены pixi.js 8 (runtime) и vite 7 (dev в client). Остальные зависимости прежние.

## Контракт

Vite: 0.0.0.0:5173, strictPort; /ws и /health проксируются на 127.0.0.1:3001.
Production build — Vite dist; tsc проверяет типы без emit для клиента.
HTML/CSS-интерфейс на русском: название, статус соединения, подключиться/отключиться,
latency по ping/pong, видимые сообщения об ошибках. Не выбирать команду и не
показывать фиктивные игровые ресурсы. Соединение идёт через origin страницы;
HTTPS использует wss. Одно подключение и один ping-таймер; очистка при disconnect,
ошибке и pagehide. Нет автоматического восстановления сессии.
Pixi рисует адаптивную декоративную сцену сверху. Текстуры травы/камня/деревьев
генерируются локально из графических примитивов, без скачивания внешних ассетов.
Декор — предпросмотр, не игровая карта и не состояние server.
При недоступности графики показать понятную ошибку; подключение остаётся доступным.
Уважать prefers-reduced-motion; адаптироваться к мобильному экрану.
