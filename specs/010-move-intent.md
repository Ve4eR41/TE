# 010 — Первая игровая проба

## Цель

Пользователь просит сохранить текущий стиль и дать попробовать игру.
Зависимости: 008–009. Читать docs/architecture.md, docs/protocol.md,
docs/config-schema.md и docs/conventions.md.

## Ограниченный контракт прототипа

- Пока это сетевая прогулка: без боя, экономики, строительства и результата.
- Для пробы первый участник — тролль, последующие — эльфы. При выходе тролля
  его место доступно новому участнику; существующие роли не меняются.
  Это временное распределение, не финальное правило matchmaking.
- Разрешено заполнить units.json временными troll/elves: hp и скорость для пробы,
  атака и стоимость нулевые. Сервер требует эти определения на старте.
- Вместимость — число спавнов карты, занятые спавны не переиспользовать.
- Сервер двигает только сущность отправителя. move задаёт точку, steer — направление
  для WASD/стрелок. Диагональ нормализуется. Скорость — из config.
- Координаты/коллизии авторитетны. Прямой путь останавливается перед препятствием,
  автоматического поиска пути пока нет. Проверять весь отрезок шага, не только конец.
- При задержке цикла движение ограничено двумя тиками; таймер учитывает реальное время.
- steer истекает без обновлений; отпускание клавиш/blur останавливает движение.
- На нуле таймера движение прекращается. Последний выход сбрасывает арену.
- Полные снапшоты содержат всех участников. Клиент интерполирует, не симулирует.
- UI: войти, выход, роль, участники, таймер, фаза, клик/тап и клавиши.
  Ошибки цели не разрывают соединение. Повторное подключение очищает старую сцену.
