# 011 — Ресурсы первой пробы

## Цель и чтение

Продолжение по просьбе пользователя. Читать docs/vision.md, docs/architecture.md,
docs/config-schema.md и docs/protocol.md. Сохранить стиль и движение 010.

## Контракт

- Добавить economy.json в GameConfig/loadConfig: starting и incomePerSecond
  по командам troll/elves. Значения gold/wood/rage конечны и неотрицательны.
- Для теста: эльфу 120 золота и 120 дерева, доход 2 золота и 3 дерева/с.
  Троллю все начальные ресурсы и пассивный доход нулевые. Ярость появится с боем.
  Это временная экономика, не утверждённый баланс; явно указать это в docs.
- Сервер начисляет по фактическому времени, включая задержку тика, только
  подключённым участникам и до конца матча. Дроби хранятся, UI показывает пол.
- Снапшот создаётся для получателя: нельзя получить чужой кошелёк.
- Выход удаляет кошелёк, новый вход начинает с начальных значений.
- Чтобы попробовать эльфа одному, добавить выбор команды в UI и параметр
  `?team=troll|elves` у /ws. Без параметра прежнее автоматическое распределение.
  Сервер не разрешает второго тролля (ROLE_TAKEN); вместимость прежняя.
- Смена команды — выход и новое подключение. Без аккаунтов, сохранений или лобби.

## Разрешённые изменения

config/economy.json, shared loader/schema/types/exports и связанные docs,
server room/transport, client HUD/выбор роли и тесты. Новых зависимостей нет.
